## 本地文件

- `播报写作规则.md` —— **写作规则的正本**：跨语言原则对照、英文去 AI 味规则、来源清单（含实测状态）、发布前检查清单、「规则改了以后改哪些稿」
- `播报查规则.js` —— 把发布前检查清单里能机器判的八条落成脚本。`node 播报查规则.js 稿件.json`（`--all` 全列），有硬伤退出码 1
- `复述判定标准.md` —— **复述判定的正本**：四维打分（结构 / 准确 / 语言 / 自主）、掌握度 0–5 档、判定怎么驱动复习排期、判定卡长什么样
- `复述台/` —— **每日英语学习台**（原复述台；目录名保持 `复述台/` 不动，发布是按目录认应用的）。两个文件：`index.html`（全部界面与逻辑）+ `guest-seed.js`（游客模式的演示素材）。带云服务后端：登录、素材与排期、复述判定与归档都在它自己的云数据库里
- `复述台/guest-seed.js` —— **只放编的演示数据**（公司名、数字、来源全部虚构）。这个文件部署后是公开可读的，真实素材一律不往这里放。它同时是 6 卷「合规样例」：那 6 篇演示稿过 `播报查规则.js` 是 0 硬伤 0 提醒，可以拿来对照什么叫没 AI 味。里面的 `_d_*` 字段是「相对今天的天数」，打开页面时才换算成真实日期，所以放久了也不会过期
- `_归档/复述台_seed.js.bak` —— 首批 6 篇素材的种子文件。它曾经能被匿名访问（`/seed.js` 200，带素材全文），已从部署目录移出来。素材的正本现在是云库
- `复述归档.py` —— 把一次判定写回学习库的脚本（旧流程用，`--dry-run` 先看会改什么）
- `每日英文播报台_离线快照.html` —— 离线可读版，数据已注入，双击就能看；**只读**，打卡要去线上页面
- `data/学习库.csv` —— 素材快照，Excel / Numbers 可直接打开
- `data/选题规则.csv` —— 选题规则快照（表里是机器可读版，`播报写作规则.md` 记依据与例句）

## 复述判定（闭环的最后一环）

打卡是自评，点一下就过。复述判定要回答的是同一件事的另一个版本：这一遍到底够不够格往前走。

**2026-10-13 改版：判定从「贴进对话」搬进了页面，入口是每日英语学习台。**

流程：

1. 打开学习台 → 「今天」列出该复习的篇目（新学的和到期的都在）。
2. 正文默认遮住；卡住了可以点「看一眼原文（10 秒）」，倒计时自动收回，偷看会记下来。
3. 对着手机讲一遍（页面内有语音转写），或者把转好的文字贴进来。
4. 点「交给 AI 判」，几秒后出结果卡：四维得分、判定、掌握度、要点。
5. 判完自动归档、推进排期；判错了点「撤销这次判定」。

之所以能这么省事：学习台有自己的云服务后端（数据库 + 免密钥调大模型），所以模型能在页面里当场判。之前的硬约束「资料库页面调不了大模型」还在，但这套链路的输入、判定、归档全在应用里，不再走页面。

规则上唯一需要留意的一点：**达标才让轮次往前走、间隔才拉长**。部分达标和未达标都原地重来，第二天再讲一次。间隔拉长的前提是记住了。

**两份台账的版本已经结束（2026-10-13）**。现在只有一份：学习台自己的云数据库。

| | 记什么 | 在哪 |

| 学习台云库 | 素材本体 + 全部进度：`materials`（素材 / `kind` 主推备选 / `skills` 训练技能点 / 排期 / 判定 / 掌握度）、`attempts`（每次复述的转写与判定） | 应用 `wbapp_1RWFmB5RskKQ3eTa1yFkl6` 的云数据库 |

旧资料库那两份台账（学习库表的复习字段、播报台页面的打卡）**不再更新**，只留作历史记录。学习库里的旧字段和应用的字段同名同义，历史上各走过各的，现在以应用为准。

## 学习台页面结构（2026-10-14）

**宽屏常驻侧栏目录 + 主列**，窄屏收成右下角「目录」按钮开抽屉。目录是全文的框架：上面一行汇总（共几篇素材 / 覆盖几天 / 今天该复习几篇 / 已巩固几篇），下面可以切「按主题」还是「按日期」归组，选的哪种记在本机（`rt_nav`）。点目录里某一篇 → 切到「篇目」并滚到那张卡、闪一下。

主列顶部一条**吸顶板块条**，四个板块点一下切换（不是靠滚动找）：

- **今天该复习**：该复习的篇目（新学的 + 到期的），今天已经动过的沉到底部、变灰、折叠，带今天几点动的。
- **篇目**：全部素材，同样可切「按主题」/「按日期」。**折叠状态只有一份**：侧栏目录和这一页的分组都挂 `data-gk`，折一边两边一起变。
- **排期**：一行一篇，写着轮次、下次复习；每行能改轮次。
- **我的积累**：四格数字（已巩固 / 跟读或录过的 / 复述判定次数 / 今天动过的篇目）+ 技能点进度条（按素材卡上的 `skills` 归拢）+ 每次复述的转写、四维得分、判定与要点。

每张素材卡：标签行（主推 / 领域 / 轮次 / 练习状态 / 上次判定 / 难度 / 播报日期）+ 元信息行（技能点 · 主题线）+ 英文标题 + 中文标题 + 按钮行（**阅读全文 / 遮中文 / 跟读打卡 / 复述这篇 / 改轮次**）+ 页脚（六个点＝新学加 5 轮，亮到哪就是练到哪，右边写下次复习哪天）。

「阅读全文」展开**七个内页**：播报稿 / 中文 / 术语表 / 商务句型 / 可说的句子 / 理解难点 / 口播结构。「遮中文」直接切到中文页并糊住，点一下显示，用来盲测。

复述页里正文默认不进页面（点开跟读折叠块才生成），遮住的地方可以「看一眼原文（10 秒）」，偷看会记在这次的记录上。

## 游客模式（2026-10-14）

改界面的时候不必每次走手机验证码。登录页下面有个「游客模式（不用验证码）」入口：

- **完全不碰云服务 SDK**：素材进度放在浏览器 `localStorage`（键 `rt_guest_v1`），所以 CDN 加载不出来也能进。
- **铺的是内置演示素材**（`guest-seed.js`），6 篇、含 5 条编的判定记录，为的是让「今天该复习」「沉底」「我的积累」「技能点进度」都不是空态。
- **不能判定**：「交给 AI 判」要点大模型，必须有登录态。点它会提示先登录，不会写坏数据。
- 顶栏下面挂着一条提示条，带「重置演示数据」和「退出游客」两个按钮。

实现上把云库调用收敛成了一个 `DB` 适配器（6 个方法：`countMaterials` / `insertMaterials` / `listMaterials` / `listAttempts` / `updateMaterial` / `insertAttempt` / `deleteAttempt`），返回形状跟 SDK 一致（`{data, error}`）；游客模式换成读写本机，上层的渲染代码一行没改。

SDK 万一加载不出来（比如 CDN 被墙），**不再堵死在启动页**：照常给登录页，并说明手机号登录暂时用不了、可以先点游客模式。这样「先看一眼界面」这条路任何情况下都走得通。

一个要知道的现状：代码里还留着 `ensureSeed()`（首次登录、库为空时从 `window.SEED_MATERIALS` 铺素材），但 `seed.js` 已经移出部署目录，所以**这条路实际不走**。新手机号登录看到的是空库，素材靠每天 08:30 的定时任务写进来。留着这段代码只是为了「哪天把 seed 放回去就能用」。
